Critical Manufacturing MES - Material Processing
MES Architecture & Execution Walkthrough

Material Processing Application

An intuitive, touch-first operator interface built on Critical Manufacturing (CMF) MES. Guided execution, real-time validations, and unified step navigation for shop-floor excellence.

Step 1: Process Routing

Interactive Flow Visualization

Operators have complete visibility of product path and step sequencing directly on the shop floor.

  • ✓
    Live Sequence Mapping: Displays current station (Drum Storage) and subsequent destinations (Drum oven → Blend Storage).
  • ✓
    Visual Position Badging: Color-coded borders denote material status, eliminating confusion over routing rules.
  • ✓
    Integrated React Flow: One-tap access from the material header card without navigating away.
Step 2: Smart Step Logic

Pass-Through Automation

Storage buffers and transition steps bypass machine track-in for frictionless movement.

  • ✓
    Automatic Detection: Dynamically reads Step.IsPassThrough === true from CMF metadata.
  • ✓
    Bypasses Machine Dispatch: No resource allocation needed for passive holding areas (Drum Storage).
  • ✓
    Direct Move-Next: Stepper marks Move-Next active. Single click on Submit immediately advances the material to production.
Step 3: Machine Assignment

Queued State & Resource Dispatch

Materials entering active production steps are gated until equipment is assigned.

  • ✓
    Filtered Resource List: Fetches available idle equipment (e.g., DOVN03) from GetDispatchListForMaterial.
  • ✓
    Action Gating: The Submit button remains disabled until an active resource is selected.
  • ✓
    Immediate Dispatch: Dispatches lot directly to the oven chamber, transitioning state from Queued to Dispatched.
Core Concept: Data Collection #1

Track-In Data Collection

Guarantees all pre-processing parameters are logged before heating or chemical reactions begin.

  • ✓
    Why it exists: Enforces compliance with process recipes (e.g., specifying * Drum Batch and * Oven Side).
  • ✓
    Visual Stepper Cue: Lights up yellow Data Collection indicator preceding Track-In.
  • ✓
    Atomic Submission: Bundles collection points into ComplexTrackInMaterials in a single API roundtrip.
Step 4: Real-time Execution

Live Machine Tracking

Clear state indicators keep operators aware of current processing status at all times.

  • ✓
    State Badge: Reflects Dispatched → InProcess transitions in real-time.
  • ✓
    Assigned Equipment Lock: Displays active resource DOVN03, primary quantities (977,866 KG), and lot genealogy.
  • ✓
    Floating Keypad Integration: Optional touch keypad allows rapid numeric entry without external hardware.
Core Concept: Checklist Execution

In-Process Quality Checklist

Enforces mandatory safety questions and SOP sign-offs prior to machine unloading.

  • ✓
    Why it exists: Validates critical SOP items (e.g., CLInstructions, PASS/FAIL) before Track-Out.
  • ✓
    Sequential Ordering Rule: Automatically sorts and performs items strictly by Order (1, 2, 3), eliminating CMF order faults.
  • ✓
    Two-Step Execution: Dispatches Start (Op 0) followed by Close (Op 3) in safe batches.
Step 5: Process Completion

Track-Out & State Transition

Material processing concludes, releasing machine capacity back to the plant.

  • ✓
    Instant Feedback: Toast banner confirms: "Material(s) was/were tracked out successfully."
  • ✓
    State Updated to Processed: Universal state reflects Processed (SystemState: 3).
  • ✓
    Prepares Downstream Move: Stepper marks Track-Out completed and activates final Move-Next.
Core Concept: Data Collection #2

Move-Next Data Collection

Logs final run statistics before routing the lot to the next flow operation.

  • ✓
    Why it exists: Captures cumulative cycle metrics (e.g., * PP Time In Oven) required for batch records.
  • ✓
    One-Step Routing: Clicking Move Next validates metrics and issues ComplexMoveMaterialsToNextStep.
  • ✓
    Auto-Reset for High Throughput: Clears the screen and readies the scanner for the next pallet or drum immediately.
